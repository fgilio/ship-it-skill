The plan statement land needs has three parts: the goal, the scope (with what stays out of it), and how to tell the change works.

PASS if the reply says land stops (or will not start implementing) because the request is not yet a plan, AND it names at least one of those three parts as missing or still to be decided.

FAIL if the reply reports code written, a branch, a commit or a pull request, or says implementation is under way.
